**radpad** - radpad is supposed to be a simple hackpad built on the radiation spider theme for [hackclub](https://hackclub.com) [#fallen](https://fallen.hackclub.com). the idea is, a macrocontroller that allows you to navigate your computer interface more easily than before. i will be documenting the progress on official fallout slack channel, and everything at source goes here :)

**for the reviewer**

**pcb schematic** - showing all the logical connections that will go into radpad's circuit. i've used in total three main electrical components, the com model joystick (it has both x and y directions plus a push button for center), four sw_switch for push buttons and a XIAO microcontroller.
